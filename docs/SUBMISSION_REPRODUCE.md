# 공개 소스 체크아웃 재현 안내

이 저장소는 금융 공시 에이전트의 애플리케이션 소스, 서빙 계약, 테스트와 설계 문서를
공개합니다. 원본 공시 코퍼스와 운영용 SQLite/FTS5 릴리즈는 공개 저장소에 포함하지
않습니다. 따라서 데이터가 필요한 파이프라인 빌드·실데이터 검색·HCX 실서빙은 승인된
운영 환경에서 별도의 데이터 공급 경로를 구성한 뒤 수행해야 합니다.

## 소스 및 계약 검증

Python 3.13.11과 `uv.lock`을 기준으로 개발 의존성을 설치합니다.

```sh
uv sync --locked --extra dev
uv lock --check
uv run pytest --collect-only -q
uv run pytest -q
```

기본 테스트는 HCX API나 외부 네트워크를 호출하지 않습니다. FastAPI 계약, HCX 요청
페이로드, 재시도·deadline 처리, 컨텍스트 패킹과 도구 계약을 로컬에서 검증합니다.
데이터 릴리즈가 없는 공개 체크아웃에서는 실데이터 무결성 게이트와 실코퍼스 검색
게이트를 실행하지 않으며, 해당 검증은 운영 자산이 준비된 환경에서만 수행합니다.

## 컨테이너 검증

```sh
cp .env.example .env
# 실서빙을 수행할 때만 로컬 .env에 HCX_API_KEY를 입력합니다.

docker compose build --pull
docker compose up -d
curl --fail http://127.0.0.1:8080/healthz
```

`/healthz`는 모델을 호출하지 않습니다. `/answer`는 검색 릴리즈와 HCX 자격 증명이
준비된 환경에서만 실행하며, API 키를 커밋·로그·질의 문자열에 포함하지 않습니다.

## 운영 자산 원칙

운영 데이터는 애플리케이션 이미지와 분리된 읽기 전용 마운트로 제공하고, 릴리즈 매니페스트와
SHA-256 검증을 통과한 경우에만 서버를 ready 상태로 전환합니다. 원본 데이터나 생성된
평가 답안은 이 저장소의 공개 커밋에 추가하지 않습니다.
